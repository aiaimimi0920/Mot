# Interaction Origin (`V0.0.1`)

Standalone G2A `V0.0.1` **Interaction Origin** polyglot multi-engine SDK suite and genre reference hosts for game developers and engine integrators.

Implements Tier 1 of [G2A_SPECIFICATION.zh-CN.md](../G2A/docs/standard/G2A_SPECIFICATION.zh-CN.md) and Chapter 2 of [G2A_PSEUDOCODE_API.zh-CN.md](../G2A/docs/standard/G2A_PSEUDOCODE_API.zh-CN.md) across **6 languages / game engines** with byte-for-byte RFC 8785 (JCS) golden parity:

- [`python/`](python/): Python 3.11+ `OriginSDK` (HTTP/1.1 Keep-Alive loopback listener + zero-inbound-port `pull://origin.execute` outbound stream + FRAND slot governance + `extensions_data` + 360° yaw-relative spatial deictics + recursive JSON Schema validator) and all **five canonical genre reference hosts** in `demo_host.py` (`spatial`, `strategy_card`, `workshop`, `deduction`, `tactical_arena`).
- [`csharp/`](csharp/): .NET 8 / Unity-compatible C# `G2A.InteractionOrigin` SDK (`OriginSdk`, `JcsDigest`, `Pose3D`, recursive JSON Schema validation, `HttpHubTransportClient.FromLocalHubDiscovery()`, `OutboundExecuteStreamClient`, `LoopbackExecuteListener`), plus a drop-in **Unity Package Manager (UPM) package** in [`csharp/UnityPackage/com.g2a.interaction-origin/`](csharp/UnityPackage/com.g2a.interaction-origin/).
- [`gdscript/`](gdscript/): Godot 4.x native addon (`addons/g2a_origin/`) including `G2AOriginSDK` (FIFO reusable `HTTPRequest` worker, `auto_discover_local_hub()`, FRAND governance exports, `attach_extension_data()`), `G2AJcs`, `G2ALoopbackServer`, `G2ASpatialAdapter3D`, and a runnable Godot 4.x project in [`gdscript/demo_project/project.godot`](gdscript/demo_project/project.godot).
- [`cpp/`](cpp/): Zero-dependency **C++17 header-only SDK** (`include/g2a/origin_sdk.hpp`, `http_transport.hpp`, `jcs.hpp`, `sha256.hpp`) featuring cross-platform WinSock2/POSIX `HTTP/1.1 Keep-Alive` transport & loopback listener, `Pose3D` 360° deictic anchors, recursive JSON Schema validation, and a drop-in **Unreal Engine 5 Plugin** (`UG2AOriginSubsystem`) in [`cpp/UnrealPlugin/G2AInteractionOrigin/`](cpp/UnrealPlugin/G2AInteractionOrigin/).
- [`rust/`](rust/): Zero-dependency pure **Rust 2021 crate (`g2a-origin`, `#![forbid(unsafe_code)]`)** for Bevy, Fyrox, Tauri, and custom Rust game servers (`OriginSdk`, pure-Rust SHA-256 + RFC 8785 JCS UTF-16 key ordering, `Pose3D`, recursive JSON Schema validation, `HttpHubTransportClient`, `LoopbackExecuteListener`, and `OutboundExecuteStreamClient`).
- [`typescript/`](typescript/): Zero-dependency **TypeScript / ES2022 universal SDK (`@g2a/interaction-origin`)** with zero-build `esm/index.mjs` runtime for HTML5 / Three.js / Phaser / Cocos / Tauri / Node 20+ games (supporting both Browser `EventSource` and universal `fetch` `ReadableStream` zero-inbound-port streaming), plus a playable **HTML5 Spatial + Workshop Hybrid Web Game** in [`typescript/web_demo/index.html`](typescript/web_demo/index.html).
