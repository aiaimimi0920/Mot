# G2A.InteractionOrigin (`0.0.1`)

Zero-dependency **.NET 8 / Unity C# Interaction Origin SDK** implementing Tier 1 of the **G2A `V0.0.1`** specification (`OriginSdk`, `JcsDigest`, `Pose3D`, recursive JSON Schema validation, `HttpHubTransportClient`, `LoopbackExecuteListener`, and zero-inbound-port `OutboundExecuteStreamClient`).
