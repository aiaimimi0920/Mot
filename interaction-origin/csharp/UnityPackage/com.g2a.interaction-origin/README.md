# G2A Interaction Origin SDK for Unity (`com.g2a.interaction-origin` `0.0.1`)

Drop-in Unity Package Manager (UPM) package implementing Tier 1 of the **G2A `V0.0.1`** specification.

## Installation in Unity Editor

1. Open **Window -> Package Manager**.
2. Click **`+` -> Add package from tarball...** and select `com.g2a.interaction-origin-0.0.1.tgz` (or **Add package from disk...** after extracting `g2a-origin-unity-upm-v0.0.1.zip` and choosing `package.json`).
3. Add `G2AUnityOriginBridge` to a GameObject and `G2ASpatialInteractable` to interactive scene props.
