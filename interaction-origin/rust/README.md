# g2a-origin (`0.0.1`)

Zero-dependency pure-Rust **Interaction Origin SDK** (`#![forbid(unsafe_code)]`) implementing Tier 1 of the **G2A `V0.0.1`** specification for Bevy, Fyrox, Tauri, and custom Rust game servers.

Includes pure-Rust FIPS 180-4 `SHA-256`, strict I-JSON + RFC 8785 (JCS) UTF-16 canonicalization, recursive JSON Schema validation, `Pose3D` 360° yaw-relative deictics, `HttpHubTransportClient`, `LoopbackExecuteListener`, and zero-inbound-port `OutboundExecuteStreamClient` (`"pull://origin.execute"`).
